Methods appendix

How each conclusion was reached

Methodology supports the case conclusions; it is not the subject of the report. The governing rule is simple: reconstruct physical motion only from measured geometry, and never use missing data as evidence for an exotic identity.

01

Normalize the archive

Separate physical source files from flattened incident rows, extract time/place/media fields, and group obvious event families to avoid double counting.

02

Score information content

Rate provenance, measurements, corroboration, time/place precision, quantitative fields, and documentation. The score says how well a claim can be tested.

03

Generate alternatives

Test common object classes, atmospheric and astronomical sources, perception, sensor processing, secret programs, and fabrication against known constraints.

04

Cross-check the corpus

Search related files for admissions, later investigations, duplicated witness accounts, alternate captions, and higher-quality versions of the same event.

05

Calibrate confidence

Separate identity confidence from evidence quality. An unresolved record can have a low-confidence conventional best fit without being “debunked.”

06

Prioritize collection

Rank follow-up by recoverable information: original telemetry, exact geometry, independent sensors, and falsifiable predictions—not narrative strangeness.

Bottom line
The reports are best explained as many different things that become visually similar when distance, darkness, speed, and sensors remove identifying detail.
No single hidden cause is required

A residue is still worth studying

“Unresolved” must remain honest

It means the released evidence cannot decide among hypotheses; it does not identify an exotic one.

The decisive experiment is better data

Calibrated multisensor observations with precise time, location, geometry, and original metadata can turn stories into testable events.
